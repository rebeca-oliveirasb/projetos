# ♻️ Projeto - Cálculo de consumo de água 🚿

Sistema criado para a companhia de saneamento da cidade, para classificar o perfil de consumo de água dos moradores, como parte de uma campanha de conscientização ambiental. O projeto foi desenvolvido em linguagem **Python**, trabalhando com **estruturas condicionais de decisão**, **operadores lógicos** e organização em **match**.

O programa solicita ao usuário **tipo do imóvel** (comercial, casa ou apartamento) e **consumo mensal de água** em m³. A partir do tipo de imóvel selecionado e do consumo informado, uma mensagem é exibida na tela indicando se o valor está controlado, dentro do esperado ou muito alto (indicando ao usuário que economize e verifique possíveis vazamentos).
