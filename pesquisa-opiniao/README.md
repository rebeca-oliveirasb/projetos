# 🔍 Projeto - Pesquisa de opinião 🗣️

Este projeto, em Python, foi criado para praticar **estrutura de repetição**, usando **estruturas de decisão** para verificar as informações.<br>

O programa foi pensado para a empresa de marketing TudoWeb, para realizar uma pesquisa de opinião referente à satisfação dos clientes com o atendimento oferecido pela empresa. São solicitados o **nome**, **idade** e a **opinião do cliente** em números, sendo 1 - excelente, 2 - bom e 3 - ruim. A partir desses dados, o sistema avalia as quantidades de opiniões **excelentes** e **ruins** e exibe o total de cada uma na tela.<br>
