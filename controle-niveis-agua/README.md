# 🎛️🌊 Projeto - Controle de Níveis de Água 👷🏻‍♀️

Projeto realizado em Python: desenvolvimento de um **sistema simples de monitoramento para um resevatório de água**, que exibe **alertas do nível de água** do reservatório, com a situação respectiva e a mensagem na cor designada.<br>

Nesse programa, foram utilizadas **listas** para armazenar os níveis e as respectivas situações, **estruturas de decisão** na definição de cores para cada nível, **funções** e **estruturas de repetição** para percorrer a lista e exibir as mensagens de cada nível já prontas com as cores, e importação da biblioteca **colorama**, responsável por colorir os textos solicitados.<br>
